# RTAI gazete üretimi

Read and apply the independent [rtai-newspaper skill](../../../skills/rtai-newspaper/SKILL.md). Its bundled scripts run without the Workshop app or npm dependencies. Install the portable `skills/rtai-newspaper` folder on another computer; this file is the repository discovery entrypoint.

Produce `.html` in the user's chosen folder (normally `.local/issues/`). The Workshop imports this versioned HTML as editable pages. Existing `.rtai.zip` packages remain supported by the repository tools. For production and revision use the portable skill above; keep production outputs separate from app source and do not publish to ERP automatically.
